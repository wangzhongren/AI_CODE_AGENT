# 设计：桌面端界面视觉改造

- 日期：2026-10-17
- 状态：客户直接要求（「这个页面太丑了」）
- 负责角色：桌面客户端（desktop-client）
- 影响路径：`desktop/`（`window.py` 为主，必要时 `app.py` 应用全局样式）
- 不改：`desktop_main.py`、`packaging/`、`.github/`、`myagent/`、`ai_agent_factory/`

## 1. 现状

当前 `MainWindow` 直接使用原生 `QTextEdit` / `QLabel` / `QLineEdit` / `QPushButton`，没有任何样式：

- 输出区是一整块纯白、无内边距、无边框层次的文本框。
- 状态只是一行默认小字。
- 输入框与发送按钮是系统默认外观，按钮与输入框等高、无主次。
- 窗口没有统一背景、没有视觉分组，整体像控件演示页。

## 2. 目标

在不改变交互流程的前提下，把窗口做成一个可用的桌面工具界面：

1. 有明确的信息层次：标题栏 → 输出区（主内容）→ 输入区（操作）。
2. 主次分明：发送是唯一主操作；其余为辅助信息。
3. 状态可见：就绪 / 运行中 / 错误 三种状态在视觉上可区分。
4. 留白与圆角统一，颜色克制，不喧宾夺主。

## 3. 视觉规格

### 3.1 布局

```text
┌──────────────────────────────────────────────┐
│  标题「代码生成助手」        ● 状态胶囊      │  顶栏（带底部分隔线）
├──────────────────────────────────────────────┤
│                                              │
│   输出卡片（白底、圆角、浅边框、内边距）     │  主内容，占满剩余空间
│                                              │
├──────────────────────────────────────────────┤
│   输入框（圆角、聚焦高亮）        [ 发送 ]   │  输入行
│   辅助提示（运行中可关闭窗口中断）           │
└──────────────────────────────────────────────┘
```

### 3.2 颜色（浅色主题）

| 用途 | 值 |
| --- | --- |
| 窗口背景 | `#F4F6F8` |
| 卡片背景 | `#FFFFFF` |
| 边框 | `#E3E8EF` |
| 主文字 | `#1D2430` |
| 次要文字 | `#6B7684` |
| 主色（发送按钮） | `#2F6FEB` |
| 主色悬停 | `#2559C7` |
| 主色按下 | `#1E47A8` |
| 主色禁用 | `#C7D6F5` |
| 错误文字 | `#B00020`（**保持不变**，测试断言精确值） |

### 3.3 字体

- 字体族回退链：`Microsoft YaHei UI` → `PingFang SC` → `Segoe UI` → `sans-serif`。
- 标题 16px / 600；正文 14px；辅助文字 12px。
- 输出区正文 14px，内边距 18px，段间距略大于行距。

### 3.4 控件细节

| 控件 | 规格 |
| --- | --- |
| 输出区 | 白底、圆角 12px、1px 边框、内边距 18px、只读、选中色主色浅调 |
| 输入框 | 高 42px、圆角 10px、内边距左右 14px、聚焦时边框变主色 |
| 发送按钮 | 高 42px、圆角 10px、白字主色底、悬停/按下/禁用三态；最小宽度 88px |
| 状态胶囊 | 圆角胶囊、浅灰底；运行中改为浅蓝底 + 主色文字；前置 8px 圆点 |
| 滚动条 | 宽 10px、圆角、浅灰滑块、悬停加深 |

### 3.5 可读性

- 错误仍用「另起一段 + 红色加粗 + `[错误]` 前缀」，与现有契约 C1 一致。
- 输出区保持等宽可选：正文用无衬线；若模型输出代码块，仍按原样显示（本轮不做 Markdown 渲染，避免扩大范围）。

## 4. 实现方式

- 在 `desktop/window.py` 内定义一个模块级常量 `WINDOW_STYLESHEET`，在 `MainWindow.__init__` 里 `self.setStyleSheet(...)`，或由 `app.py` 用 `application.setStyleSheet(...)` 应用。**优先窗口级**，避免影响离屏测试里其它共用 `QApplication` 的用例。
- 保持所有 `objectName`：`mainWindow`、`outputPane`、`statusLabel`、`requirementInput`、`sendButton`。测试靠它们找控件。
- 保持控件类型不变（`QTextEdit` / `QLineEdit` / `QPushButton`），否则 `findChild` 会失配。
- 保持 `ERROR_COLOR` 常量与错误渲染逻辑不变。
- 保持所有公开方法签名不变（`display_token` / `display_turn_completed` / `display_error` / `set_busy` / `finish_task` / `handle_send` / 两个 `set_*_handler`）。
- 契约 C3：`desktop/__init__.py` 仍然不得在导入时加载 Qt。本改动只碰 `window.py`（本来就依赖 Qt）。
- 不新增生产依赖。
